# ClipStudio Web — distribusi server terpisah
Satu ruang kerja privat pada server Linux dengan Docker. Browser mengedit, server mengambil video dan menjalankan transkripsi, rekomendasi serta ekspor. Tidak terhubung dengan SIRUSA. Akses awal melalui SSH tunnel, bukan port publik. Tanpa API berbayar. Tampilan studio gelap, fokus keyboard terlihat, tanpa aset eksternal. Simpan hasil edit per klip. Pendekatan Python + FFmpeg dipilih agar tidak perlu layanan data tambahan. Peringkat rekomendasi memakai sinyal transkrip, bukan prediksi penonton. Framing wajah memakai estimasi visual.
